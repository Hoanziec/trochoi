# Đường Cao Trên Lưới Ô Vuông

Trò chơi tương tác môn Toán (xác định đỉnh đối diện, cạnh đáy và vẽ đường cao tam giác trên lưới ô vuông), chạy trực tiếp trên trình duyệt máy tính và điện thoại.

## Thành phần trong gói
- `index.html`: File trò chơi hoàn chỉnh (bao gồm 3 chế độ: *Bắt Đỉnh - Bắt Đáy*, *Giải Cứu Đường Cao Lạc*, *Chạm Vẽ Đường Cao*).

## Cách xuất bản lên GitHub Pages
1. Giải nén file `.zip` này để lấy `index.html`.
2. Tạo một repository mới trên GitHub và tải `index.html` lên thư mục gốc.
3. Vào **Settings -> Pages**, chọn nhánh chính (`main`) và thư mục `/ (root)`, sau đó lưu lại.
4. Truy cập địa chỉ GitHub Pages được tạo để sử dụng trên máy tính hoặc điện thoại.
